# План розробки: Telegram Translation DeepL & Multi-LLM Bot

## Версія: v0.2.2

### Мета проекту
Створення високопродуктивного, асинхронного Telegram-бота для автоматичного двонаправленого перекладу (Українська $\leftrightarrow$ Інші мови) з підтримкою **DeepL (Standalone)** та передових моделей через **OpenRouter** (Gemini 3.5 Flash Lite, Gemini 3.7 Flash, OpenAI GPT-5.6 Luna, DeepSeek V4 Flash) у Non-Thinking mode, автоматизованим розгортанням у каталог користувача `~/tg_translation_DeepL_bot` на Ubuntu Server.
