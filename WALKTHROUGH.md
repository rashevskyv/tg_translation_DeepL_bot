# Журнал змін (Walkthrough)

## Версія: v0.1.1 (Виправлення розпізнавання мов та інтеграція нормалізатора DeepL/OpenAI)

### Зміни та виправлення:
1. **Інтелектуальний нормалізатор мов (`src/services/language_normalizer.py`):**
   - Додано вичерпний вбудований словник назв мов українською («Португальська», «Німецька», «Іспанська», «Польська», «Французька», «Японська» тощо) з прямим мапінгом на стандартизовані англійські назви та офіційні цільові коди DeepL (`PT-PT`, `DE`, `ES`, `PL`, `FR`, `JA` тощо).
   - Інтегровано інтелектуальне розпізнавання через **OpenAI API** для довільних складних або рідкісних назв мов будь-якою мовою світу (JSON structured parsing).
   
2. **Виправлення помилки DeepL 400 Bad Request (`target_lang not supported`):**
   - Виправлено `_map_language` у `src/services/providers/deepl_provider.py`. Тепер при виборі «Португальська» в DeepL автоматично передається валідний код `PT-PT` замість спроб обрізання кирилиці.
   - Додано зрозуміле попередження, якщо користувач вказує мову, яку DeepL не підтримує (наприклад, грузинська чи хінді), з підказкою перемкнутися на OpenAI, Gemini або DeepSeek у меню `/settings`.

3. **Покращення інтерфейсу Telegram:**
   - При зміні мови бот показує стандартизовану назву та статус підтримки DeepL:
     `Target language successfully updated to: Portuguese (DeepL Code: PT-PT)`.

4. **Тестування:**
   - Створено `tests/test_normalizer.py` з тестами для українських назв мов, кодів та валідації помилок DeepL.
   - Всі 20 тестів виконано паралельно (`pytest -n auto`), 100% успіх.

## Версія: v0.1.0 (Ініціалізація та перший реліз)

### Реалізований функціонал:
- Підтримка 5 рушіїв перекладу: DeepL, OpenAI (GPT-4o-mini), Gemini (Gemini 2.0 Flash), Qwen (Qwen-Plus), DeepSeek (DeepSeek-Chat).
- Автоматичний двонаправлений переклад (Українська $\leftrightarrow$ Інші мови).
- Стрімінг відповідей у реальному часі та фінальний вивід у тегах коду для копіювання в один клік.
- Повні GUI налаштування `/settings`, збереження персональних API ключів з автовидаленням із чату.
- Юніт-файл `systemd/tg-translator.service` для Ubuntu.
