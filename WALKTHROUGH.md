# Журнал змін (Walkthrough)

## Версія: v0.5.3 (Конвертація Markdown у Telegram HTML для жирного шрифту та форматування)

### Зміни:
1. **Конвертер Markdown у Telegram HTML (`src/utils/formatter.py`):**
   - Створено функцію `markdown_to_telegram_html(text)`, яка безпечно екранує спецсимволи HTML і коректно конвертує:
     - `**текст**` $\rightarrow$ `<b>текст</b>` (жирний шрифт замість сирих зірочок)
     - `*текст*` $\rightarrow$ `<i>текст</i>` (курсив)
     - `` `код` `` $\rightarrow$ `<code>код</code>` (інлайн код)
     - ```` ```код``` ```` $\rightarrow$ `<pre><code>код</code></pre>` (багаторядковий блок коду)
   - Підключено у `src/handlers/translation.py` для повідомлень Асистента.

2. **Тестування:**
   - Додано `tests/test_formatter.py`.
   - Всі 33 тести успішно виконані паралельно (`pytest -n auto`).
