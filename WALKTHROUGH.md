# Журнал змін (Walkthrough)

## Версія: v0.1.0 (Реліз першої версії)

### Реалізований функціонал:
1. **Мультипровайдерна архітектура перекладу:**
   - **DeepL:** підтримка безкоштовних ключів (`:fx`) та Pro-версії, точний переклад.
   - **OpenAI:** підтримка GPT-4o-mini зі стрімінгом токенів.
   - **Google Gemini:** надшвидкий переклад на базі Gemini 2.0 Flash через асинхронний REST/SSE стрімінг.
   - **Qwen:** переклад через Alibaba Cloud DashScope API зі стрімінгом.
   - **DeepSeek:** переклад через DeepSeek API (`deepseek-chat`) зі стрімінгом.

2. **Двонаправлена інтелектуальна трансляція:**
   - Український текст $\rightarrow$ автоматично перекладається на обрану користувачем мову (за замовчуванням: English).
   - Неукраїнський текст $\rightarrow$ автоматично розпізнається мова джерела та перекладається на українську.

3. **Стрімінг та One-Click Copy UX:**
   - Проміжний процес генерації відображається у реальному часі через стрімінг із контролем частоти оновлень (throttling), щоб не перевищувати ліміти Telegram.
   - Після завершення перекладу проміжне повідомлення видаляється, а фінальний результат надсилається всередині блоку коду (`<pre><code>...</code></pre>`). Це дозволяє користувачеві скопіювати весь переклад у буфер обміну одним кліком у клієнті Telegram.

4. **Інтерактивне GUI-меню налаштувань (`/settings`):**
   - **Встановлення мови перекладу:** натискання кнопки перемикає бота в режим очікування введення назви або коду мови (наприклад, `German`, `Polish`, `es`, `English`).
   - **Вибір моделі/провайдера:** зручне перемикання між 5 провайдерами через Inline кнопки.
   - **Керування персональними API ключами:** перегляд статусу (маскований вигляд), додавання та видалення персональних ключів. Повідомлення користувача з API ключем **автоматично видаляється** з чату для запобігання витоку.

5. **Безпека та конфіденційність:**
   - Чутливі дані, файл `.env` та база даних `*.db` захищені правилами `.gitignore`.
   - Ключі та вибір користувача ізольовано зберігаються у локальній базі даних SQLite (`data/translator.db`).

6. **Деплой та системний сервіс:**
   - Підготовлено systemd юніт `systemd/tg-translator.service` для цілодобового запуску на сервері Ubuntu Linux з автоматичним перезапуском.

7. **Тестування:**
   - 16 автоматизованих тестів модулів детекції мови, бази даних, провайдерів та менеджеру перекладів протестовано у паралельному режимі за допомогою `pytest -n auto`.
