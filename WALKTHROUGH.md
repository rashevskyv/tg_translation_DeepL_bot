# Журнал змін (Walkthrough)

## Версія: v0.3.0 (Режим інтелектуального асистента з уточненням контексту та окремою моделлю)

### Зміни:
1. **Інтеграція режиму асистента (Assistant Mode):**
   - Додано сервіс `src/services/assistant.py`.
   - Якщо увімкнено режим асистента (`Assistant Mode`):
     - Модель асистента аналізує вхідний текст на предмет неоднозначності, сленгу, подвійних сенсів або незрозумілого контексту.
     - Якщо є сумнів або двозначність: бот **перепитує у користувача** українською мовою, уточнює нюанси, стиль і значення.
     - Після отримання відповіді бот формує ідеальний, вивірений переклад у тегах `<code>...</code>`.
     - Якщо текст 100% однозначний і простий: перекладає одразу без зайвих запитань.

2. **Вибір окремої моделі для асистента (Assistant Engine):**
   - У налаштуваннях (`/settings`) додано можливість обрати окрему модель для асистента (Gemini 3.7 Flash, GPT-5.6 Luna, Gemini 3.5 Flash Lite, DeepSeek V4 Flash).
   - Рушій перекладача (Translator Engine) та рушій асистента (Assistant Engine) налаштовуються незалежно!

3. **База даних (`src/database/db.py`):**
   - Додано поля `assistant_mode` та `assistant_provider` з автоматичною міграцією існуючої БД.

4. **Тестування:**
   - Створено модульні тести для сервісу асистента та оновлених налаштувань (`tests/test_assistant.py`).
   - Всі 27 тестів успішно виконані паралельно (`pytest -n auto`).
