# Журнал змін (Walkthrough)

## Версія: v0.2.3 (Чистий вивід перекладу та інтелектуальне розпізнавання цільової мови через DeepSeek V4)

### Зміни:
1. **Чистий вивід результатів перекладу (`src/handlers/translation.py`):**
   - Прибрано інлайн-кнопку `[ ⚙️ Settings ]` під повідомленнями перекладу. Повідомлення тепер містить виключно перекладений текст у тегах `<code>...</code>` для миттєвого копіювання при кліку без зайвих елементів.
   - Виклик налаштувань виконується через меню: кнопкою `⚙️ Settings` на клавіатурі під полем вводу, синьою кнопкою **[ Меню ]** Telegram або командою `/settings`. Меню налаштувань відображається окремим повідомленням з кнопками.

2. **Інтелектуальне розпізнавання довільного тексту для вибору мови (`src/services/language_normalizer.py`):**
   - У режимі вибору цільової мови користувач може написати будь-яку фразу, наприклад: *"хочу перекладати на португальську, європейський варіант"*, *"постав німецьку будь ласка"*, *"перемкни на польську"*.
   - Запит надсилається до **DeepSeek V4 Flash** (`deepseek/deepseek-v4-flash-0731` через OpenRouter), який вилучає цільову мову та перетворює її на офіційну назву та код стандарту DeepL API (наприклад, `Portuguese` / `PT-PT`, `German` / `DE`).

3. **Тестування:**
   - Додано тест для розпізнавання довільних розмовних запитів моделлю DeepSeek V4 Flash.
   - Всі 24 тести успішно пройшли в паралельному режимі (`pytest -n auto`).
