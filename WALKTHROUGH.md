# Журнал змін (Walkthrough)

## Версія: v0.5.0 (Tool-Calling Архітектура для Асистента з автономним викликом інструменту перекладача)

### Зміни:
1. **Tool / Function Calling для Асистента (`src/services/assistant.py`):**
   - Перероблено роботу асистента: тепер перекладач надається моделі як інструмент `translate_text(source_text="...")`.
   - **Роль асистента:** допомагає користувачеві розібратися з думками, скласти текст, підібрати тон (сарказм, дружній, офіційний, підйобний), пропонує варіанти та веде діалог.
   - **Виклик інструменту:** коли думку сформовано та узгоджено (користувач каже *"перекладай"*, *"супер"*, *"давай 2-й варіант"*, або надіслав готовий текст без питань), асистент **викликає інструмент `translate_text`**.
   - Бот перехоплює виклик інструменту та передає узгоджений текст у обраний рушій перекладу (DeepL Standalone або обрану LLM).

2. **Зворотний переклад для верифікації:**
   - Після виконання перекладу бот автоматично додає зворотний переклад українською мовою для перевірки змісту.

3. **Тестування:**
   - Оновлено модульні тести `tests/test_assistant.py` для перевірки роботи інструменту `translate_text`.
   - Всі 30 тестів успішно виконані паралельно (`pytest -n auto`).
